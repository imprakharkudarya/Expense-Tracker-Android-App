# Expense Tracker Android App

A simple and user-friendly Android application to manage daily income and expenses, track transactions, and calculate the available balance.

## Features

- **Add Income:** Record income transactions.
- **Add Expenses:** Record daily expenses.
- **Automatic Balance Calculation:** Calculate the available balance based on income and expenses.
- **Transaction History:** View recorded transactions.
- **Delete Transactions:** Delete transactions with a long press and confirmation.
- **Local Data Storage:** Save transaction data on the device.
- **Data Persistence:** Retain saved data when the app is closed and reopened.
- **Offline Support:** Use the app without an internet connection.
- **Simple User Interface:** Clean and easy-to-use design.

## Technologies Used

- **Language:** Kotlin
- **UI Design:** XML
- **IDE:** Android Studio
- **Local Storage:** SharedPreferences and JSON
- **Platform:** Android

## How to Run the Project

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the downloaded project folder.
4. Allow Gradle to sync and complete the project setup.
5. Run the app on an Android emulator or a connected Android device.
